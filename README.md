# Dayframe

A single-page daily time-blocking planner. Open `index.html` in a browser, or use the GitHub Pages link for this repository.

Your data is stored in the browser you use, so each browser or device keeps its own copy. Use Backup to save a file you can restore later.

The app icon is "Report Columns" from [Iconoir](https://iconoir.com), released under the MIT License.
